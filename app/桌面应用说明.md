# LearningCI 桌面应用说明

技术：Python + PyQt6 + SQLite。

主页面：

- **今日学习**：当前节点、任务树、任务计时、工程证据、固定试卷预览；
- **冻结计划**：查看 68 个节点、执行包状态、固定试卷、学习状态和分数；
- **节点准备**：三节点窗口内导出细化包、导回 ChatGPT 结果；
- **复测队列**：处理延迟复测与薄弱节点；
- **学习统计**：日 / 周 / 月专注时间、任务完成度和评分；
- **想法停车场**：只记录临时想法，不允许因此切路线；
- **数据同步**：生成 / 恢复 SQLite 一致性快照。

LearningCI 不连接任何模型 API。节点细化与考试评分都通过人工复制/导入完成。
