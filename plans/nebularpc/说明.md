# NebulaRPC 冻结学习计划

这个目录分成四层：

- `NebulaRPC总计划.md`：为什么这样学、最终要证明什么能力；
- `plan.json`：固定 Node 顺序与能力边界，LearningCI 用它决定主线；
- `节点执行包/<NODE>.json`：某个 Node 具体怎么做、叶子任务和首次固定试卷；
- `导出/节点细化/`：手工导出给 ChatGPT 的节点细化 ZIP。

`plan.json` 不允许日常修改。

未来 Node 的执行包允许在**尚未开始、没有学习记录、没有冻结**时细化。细化流程必须走 LearningCI 的“节点准备”页面，不能手工覆盖已经冻结的文件。
