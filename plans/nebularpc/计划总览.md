# NebulaRPC 冻结计划总览

本文件用于人工快速查看路线。真正的路线合同是 `plan.json`；某个节点的具体打卡任务和首次固定试卷保存在 `节点执行包/<Node>.json`。

四层关系：

```text
NebulaRPC总计划.md      为什么这样走、最终要证明什么
        ↓
plan.json               节点顺序与能力边界（冻结）
        ↓
节点执行包/<Node>.json   这个节点具体怎么做、怎么验收
        ↓
learningci.db           你实际做了什么、用了多久、考了多少分
```

`节点执行包` 有三种状态：

- 草稿（待细化）：基础版本，只保证路线完整，不允许正式学习。
- 已审核（可冻结）：已通过“导出 ZIP → ChatGPT 细化 → 导回 JSON → 本地校验”。
- 已冻结：进入当前主线后自动冻结，此后不允许覆盖。

LearningCI 只允许细化“当前节点 + 后面两个主线节点”，不提前精修遥远节点。
