# 13. LearningCI Desktop v0.3.0

## 1. 中文优先

用户界面和说明文件尽量使用中文。保留 Node、Title、C++/Linux/API 等常见技术词；机器 JSON 内部键名不要求用户理解或修改。

## 2. 今日学习

- 当前冻结 Node；
- 展开式详细任务树；
- 每个叶子任务独立打卡；
- 总专注时间 + 单任务时间；
- 日 / 周 / 月汇总；
- 工程证据记录；
- 固定试卷从节点开始即可预览；
- required 任务未完成时禁止正式验收。

## 3. 节点准备

不接任何 AI API。

```text
导出节点细化 ZIP
→ ChatGPT
→ 返回 JSON
→ 本地校验
→ 用户确认
→ 已审核
→ 到达主线时自动冻结
```

只允许准备当前和后面两个主线节点。

## 4. 正式验收

五维固定：

```text
解释 15
预测 15
实现 25
诊断 25
迁移 20
```

ChatGPT 只提供分数与证据说明，本地程序重新计算总分和各维度 Gate，AI 不能直接决定通过。

## 5. 数据同步

- `data/learningci.db`：当前电脑实时数据；
- `sync/learningci.db`：SQLite backup 一致性快照。

避免直接 Git 提交正在运行的 WAL 数据库。
