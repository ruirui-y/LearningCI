# 05. 路线冻结与复盘

## 1. 为什么需要路线冻结

LearningCI 默认认为：

> 学习者最容易在“寻找更优路线”时失去执行连续性。

因此把路线设计和路线执行彻底分离。

## 2. 14 天冻结

建议每次规划后冻结：

> 14 天。

冻结期间：

- 普通学习日不能修改主路线
- 可以记录问题
- 可以新增 Parking Lot
- 可以补最小必要前置
- 不允许因为新兴趣整体改道

## 3. 合法复盘窗口

每 7 或 14 天进入一次 Route Review。

只有这个窗口允许：

- 调整顺序
- 拆节点
- 删除明显错误节点
- 改前置依赖
- 改优先级

## 4. 路线调整的合法依据

只能来自：

```text
正式测试结果
+
前置依赖关系
+
参考项目真实需求
+
Parking Lot 累积证据
```

不能来自：

- 热门趋势
- 临时兴趣
- 新教程
- 某个博主说法
- “感觉有更短路径”

## 5. Emergency Unlock

如果确实需要提前解锁路线，建议软件要求：

1. 输入解锁原因
2. 选择证据类型
3. 强制等待 24 小时
4. 第二天再次确认
5. 留下永久记录

目的是阻止冲动切换，而不是完全禁止调整。

## 6. 复盘输出

每次复盘只输出：

- 保留节点
- 调整节点
- 拆分节点
- 新增最小前置
- 延后节点
- 下一个 14 天冻结路线

复盘结束后立即重新冻结。
