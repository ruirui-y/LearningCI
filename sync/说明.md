# SQLite 跨设备同步说明

`data/learningci.db` 是当前电脑正在使用的数据库，不直接提交 Git。

`sync/learningci.db` 是通过 SQLite 官方 backup API 生成的一致性快照，可以提交到你自己的 **私有数据仓库**，用于换电脑后恢复。

## 推荐流程

旧电脑：

1. 正常结束学习；
2. 打开 LearningCI → **数据同步**；
3. 点击“生成 / 更新 Git 同步快照”；
4. 提交 `sync/learningci.db` 并 push。

新电脑：

1. pull 最新仓库/数据；
2. 如果本地数据库不存在，LearningCI 会优先从 `sync/learningci.db` 恢复；
3. 或在“数据同步”页面手工恢复。

不要在两台电脑上同时产生不同学习记录后再试图 merge 两个 SQLite 文件。一个时间点只保留一个最新写入端。

如果 LearningCI 代码仓库是公开仓库，不建议公开提交个人学习数据库；答案、评分、专注时间、薄弱点等都属于个人记录。
